# Campus Hero — AI 캠퍼스 시설 제보·관제 웹앱

> 경희대학교 6팀 · 영어실전파
> "AI가 캠퍼스를 지킵니다"

학생이 캠퍼스 시설 문제를 사진으로 제보하면, AI(Gemini Vision)가 사진의 진위와
긴급도를 판별해 실제 지도에 등록하고, 좋은 제보에는 리워드를, 허위 제보에는 제재를
주는 캠퍼스 시설 관제 웹 애플리케이션입니다.

---

## 실행 방법

별도의 설치나 빌드가 필요 없습니다.

1. `index.html` 파일을 웹 브라우저(Chrome 권장)에서 엽니다. (더블클릭)
2. 우측 상단 톱니바퀴(⚙️) → **Gemini API Key**를 입력하고 저장합니다.
3. 사진 업로드 + 위치 입력 후 **제보하기**를 누르면 AI가 분석합니다.

> Gemini API 키는 [Google AI Studio](https://aistudio.google.com/)에서 발급받을 수 있습니다.
> 입력한 키는 브라우저(localStorage)에만 저장되며 외부로 전송되지 않습니다.

### 데모 모드 (API 키 없이 체험)

API 키가 없어도 기능을 체험할 수 있습니다.

- 설정(⚙️) → **데모 모드**를 켜고 저장하면, 실제 API 호출 없이 미리 준비된
  분석 결과로 전체 흐름(제보 → 분석 → 지도 등록 → 리워드/제재)을 체험할 수 있습니다.
- 실제 AI 판별을 확인하려면 데모 모드를 끄고 API 키를 입력하세요.

## 주요 기능

### 학생 제보
- 사진 업로드(갤러리) 및 **모바일 후면 카메라 촬영** 지원
- 위치 입력 시 **건물 약칭 자동 인식** (예: "전정대" → 전자정보대학)
- 상세 설명 입력
- AI 분석 결과 카드: 진위 판별 / 카테고리 / 긴급도 / 권장 조치 / 연동용 JSON

### AI 분석 (Gemini Vision)
- **진위 판별**: 모니터 재촬영, 합성 이미지, 무관한 사진(음식·밈 등)을 감지해
  허위 제보를 자동 반려
- **자동 분류**: 카테고리(안전 위험 / 시설 고장 / 기물 파손 / 청결 및 환경)와
  긴급도(RED / YELLOW / BLUE)를 판정
- 긴급도 기준은 재난 트리아지(3색 체계)와 시설·IT 운영의 우선순위(P1~P4) 원리를
  참고해, 문제 종류 + 안전 영향 + 규모를 함께 평가

### 실시간 캠퍼스 맵
- 실제 지도(Leaflet + OpenStreetMap) 위에 제보 위치를 핀으로 표시
- 위치 텍스트를 **건물 좌표 데이터베이스와 매칭**해 해당 건물에 정확히 등록
- 같은 건물 제보는 하나의 핀으로 묶고 누적 건수 표시, 가까운 핀은 자동 분산
- 처리 상태(접수/처리중/완료)를 핀 색상에 반영

### 리워드 & 이용 제한
- 정상 제보 5회마다 교내 카페 커피 쿠폰 지급 (QR 코드 사용 처리)
- 허위 제보 3회 누적 시 제보 기능 이용 제한

### 관리자 관제 대시보드
- 긴급/대기/완료 통계, 상태·긴급도별 필터
- 제보별 사진 확인, **긴급도 최종 확정/조정** (AI 1차 판별 → 사람 최종 검수)
- 처리 상태 변경 → 지도에 즉시 반영

## 기술 스택

- **Frontend**: HTML, TailwindCSS (CDN), Vanilla JavaScript — 모바일 반응형 다크 UI
- **AI**: Google Gemini Vision API (이미지 + 텍스트 멀티모달 분석)
- **지도**: Leaflet + OpenStreetMap (API 키 불필요)
- **저장소**: 브라우저 localStorage (제보 · 리워드 · 맵 데이터)

> 참고: 사진의 진위·유형·긴급도 판별은 생성형 AI(Gemini Vision)가 수행하며,
> 지도 핀 등록은 AI가 판별한 위치 텍스트를 건물 좌표 데이터베이스와 매칭하는
> 규칙 기반 로직으로 처리합니다.
